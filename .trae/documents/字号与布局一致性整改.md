# 字号刻度与布局一致性整改

## Context

上一轮对全项目做了视觉巡检（iPad 1376×1032 预览，设计基准宽 1568），发现四类问题：

1. 各页面缩放基准不同（`--a`=vw/1568、`--e`/`--r`=vw/1376、`--u`=clamp），正文与标题跨页大小跳变；
2. 页面标题写法各异：考勤 36a、Employer 29e、E-Attendance 明细 32a、History/Reviews/Write Review/登录页都有 34px 硬编码；
3. 字号靠 `+5px / +3px` 拼凑，同类文字在不同页面不统一；下拉菜单字号为固定 20px；
4. 考勤/明细/历史三个列表页右下固定的「+」按钮遮挡表格最后一行；Time In 时间卡内部略挤。

用户已确认按此方向整改，目标是跨页视觉一致，不改变业务与信息架构。

## 方案

保持 `--a = 100vw / 1568` 为唯一字号基准，新增标题令牌 `--fs-title`，把「px 微调」收敛到统一刻度。

### 1. 标题令牌（核心）

在 [attendance.css](file:///g:/YY%20Business%20APP/src/attendance.css) 的 `.attendance-page` 令牌块中新增：

```css
--fs-title: max(calc(36 * var(--a)), 26px);
```

并把 `.attendance-header h1`（约 91 行）的 `calc(36 * var(--a))` 改为 `var(--fs-title)`。

### 2. 各页标题对齐 `--fs-title`

| 文件 | 位置 | 改动 |
| --- | --- | --- |
| [employer.css](file:///g:/YY%20Business%20APP/src/employer.css) | 约 23 行 `.employer-header h1`；约 64 行 `@media (min-width:1001px)` 的 34px 覆盖 | 均改为 `var(--fs-title)` |
| [e-attendance.css](file:///g:/YY%20Business%20APP/src/e-attendance.css) | 约 548 行 `.h-det-page .attendance-header h1` 的 `calc(32*var(--a))` | 改为 `var(--fs-title)` |
| [reviews.css](file:///g:/YY%20Business%20APP/src/reviews.css) | 约 7 行 `max(calc(34*var(--r)),26px)` | 改为 `max(calc(36 * (100vw / 1568)), 26px)` |
| [write-review.css](file:///g:/YY%20Business%20APP/src/write-review.css) | 约 5 行 h1 的 34px | 改为 `max(calc(36 * (100vw / 1568)), 26px)` |
| [index.css](file:///g:/YY%20Business%20APP/src/index.css) | 约 234 行 `@media (min-width:1001px)` 的 34px | 改为 `max(calc(36 * (100vw / 1568)), 26px)` |

### 3. Employer 页字号统一到考勤刻度

[employer.css](file:///g:/YY%20Business%20APP/src/employer.css) `.employer-page` 增加：

```css
--a: calc(100vw / 1568);
--fs-title: max(calc(36 * var(--a)), 26px);
--fs-body: max(calc(22 * var(--a)), 17px);
--fs-secondary: max(calc(20 * var(--a)), 15px);
--fs-label: max(calc(18 * var(--a)), 14px);
```

布局仍沿用 `--e`（vw/1376），只有文字改用与考勤页相同的刻度（1376 宽下正文 24→19.3、次要 16→17.6、标签 15→15.8）。

### 4. 收敛「+Npx」拼凑

- [e-attendance.css](file:///g:/YY%20Business%20APP/src/e-attendance.css)：24 / 330 行 `--fs-secondary + 5px`、41 / 339 行 `--fs-body + 5px`、584 行 `+ 3px` → 统一 `+ 2px`。
- [staff-clothing.css](file:///g:/YY%20Business%20APP/src/staff-clothing.css)：90 / 258 行 `+ 3px` → `+ 2px`（其余 +1px 为细节修饰，不动）。
- 移动端媒体查询里的固定 16/17/20/22px 属于小屏专用覆盖，保持不动，避免在手机上反而变小。

### 5. 下拉菜单字号统一

- [select-menu.css](file:///g:/YY%20Business%20APP/src/select-menu.css) 约 67 行 `.app-select-menu button` 的 `font-size: 20px` → `var(--fs-body, 18px)`。
- 删除 [labour.css](file:///g:/YY%20Business%20APP/src/labour.css) 约 240–243 行 `.lr-select .app-select-menu button` 里重复的 `font-size` 覆盖（保留 `min-height`）。

### 6. 修固定按钮遮挡最后一行

`.attendance-table-scroll` 被 AttendancePage、EAttendanceDetailPage、HistoryDetailPage 三页共用；在该规则（[attendance.css](file:///g:/YY%20Business%20APP/src/attendance.css) 约 126 行）加：

```css
padding-bottom: calc(112 * var(--a));
```

固定按钮占据视口底部 52a–140a，扣除页面 36a 内边距后约 104a，112a 可完整让开，且只在滚动到末尾时表现为留白。

### 7. Time In 时间卡内部留白

[attendance.css](file:///g:/YY%20Business%20APP/src/attendance.css) 约 156 行 `.attendance-time-card`：`height: 84a → 92a`，`padding: 7a → 5a`。

`td` 固定高 115a、上下内边距 10a，内容区 95a，92a 仍有余量；签名/二维码 + 时间的组合垂直居中更稳，不会顶到单元格边线。

## 验证

1. `npx tsc --noEmit` 通过（纯 CSS 改动，主要确认无编译问题）。
2. 浏览器打开 `http://localhost:8443/?viewport=ipad`，逐页实看：
   - 登录页 → Employer → Attendance → E-Attendance 明细 → History 明细 → Labour Requisition → Reviews / Write Review；
   - 检查：各页 h1 视觉一致（约 31.6px）、正文大小不再跨页跳变、下拉菜单字号与正文一致；
   - 考勤/明细/历史页滚动到底，最后一行 Action 列不被「+」按钮遮挡；
   - Time In 列的签名/二维码 + 时间上下留白均衡。
3. 分辨率切到 iPad 竖屏 / 手机宽度 600px 以下，确认小屏媒体查询未被破坏。
